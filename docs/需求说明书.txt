项目概述：用于对学校的课程进行管理，并对各种权限的人员提供各自的课表查询和管理功能。本项目为个人长期项目（非课程作业）：以课表为主线，后续向"大学教学模拟"演进（学生自动选课、专业课自动导入、个体行为、活的校园环境）。

用户角色：
超级管理员：可以登录，可以对整个系统进行任意修改，具有最高权限，可以直接进入后台对无法通过正常流程解决的问题进行处理，比如修改教师、管理员、学生的手机号、学生的学号
管理员：可以登录，拥有较高权限，可以对学期、院系、专业、班级、学生、教师、教室、课程的信息进行增删改查，进行开课管理、排课管理（由系统自动检测冲突），并按班级/教师/教室查询课表
教师：可以登录，可以看到自己的课程安排，并拥有调课权限（需经管理员同意）
学生：可以登录，可以查询自己的课表，自由选择选修课程

业务规则：
1. 排课冲突：同一时间，教师/教室/班级不能同时被两门课占用（单双周不同则不冲突）
2. 调课流程：教师发起 → 管理员审批通过后才生效
3. 学生课表 = 班级必修课 + 个人选修课
4. 选课范围：学生只能选"选修"性质的课程；必修课程与专业绑定，自动导入

开发计划（v1 主线）：
阶段一 MVP：全部基础数据 CRUD + 开课管理 + 排课管理（含冲突检测）+ 课表查询
阶段二：登录与角色权限 + 教师/学生查看个人课表 + 学生选课/退课
阶段三：教师发起调课 + 管理员审批 + 节假日停课

v2 路线图（大学教学模拟）：
最小可玩版本：学期推进 → 课程自动合法导入（专业课按培养方案自动开课 + 自动排课无冲突 + 学生自动选课）
后续扩展：培养方案表、学生个体行为、成绩/考试、更多教学维度
